# 呀呀法语（french-learner）

> 像婴儿一样，自然地学会法语。Web 形态，终点 B2（外派可用）。

## 产品理念

体验层走"婴儿式"——可理解输入、先听后说、情境化内容、**重述式纠错（recast）**、低情感过滤；
引擎层走"成人式"——CEFR 定位、FSRS 复习、AI 诊断、B2 考级专项。

核心差异化：用户说错时不给红叉，而是由 AI 顺着语义自然接话，把正确说法"重述"回去。

## 当前状态：前端 Demo

- `demo.html`：单文件交互原型，零外部依赖，浏览器直接打开即可。
- 展示 4 个场景（咖啡馆点单 / 和同事聊周末 / 问路 / 看医生）的对话界面。
- 点击带 ⚠ 的句子可体验"说错 → AI 自然重述纠正，不打回"的核心交互。
- **语音输入**：点麦克风用浏览器原生 Web Speech API 识别法语（`fr-FR`），需允许麦克风权限，
  建议 Chrome / Edge；也可在输入框直接打字后回车或点发送。
- 识别后的回复为**预置脚本 + 关键词匹配模拟**，非真实 AI 调用；正式版接 Whisper + LLM 实时生成重述。

## 用法

直接双击 `demo.html` 在浏览器打开；或起静态服务：

```bash
cd tools/french-learner
python -m http.server 8080
# 浏览器访问 http://localhost:8080/demo.html
```

## 后续规划（路线图）

| 阶段 | 内容 |
|------|------|
| 0 地基 | 用户档案 + CEFR 定级 + 场景词库数据管线 |
| 1 尖刀 | 重述式 AI 口语陪练（Whisper ASR + LLM + TTS） |
