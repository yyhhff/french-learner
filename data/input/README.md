# 输入流语料说明（data/input）

本目录存放「呀呀法语」阶段二 · 主线 B（i+1 可理解输入流）的语料文件。

## texts.json

分级语料主文件，格式严格遵循 `docs/ARCHITECTURE_V2.md` §5.4 的 JSON Schema，由后端 `seed_input.py::load_input_corpus()` 在启动时幂等加载入 SQLite。

- 覆盖 **A2 / B1 / B2** 三个等级，每级 7 篇（4 篇对话 + 3 篇短文），合计 21 篇；`dialogue` 与 `monologue` 搭配。
- 每篇含整篇法语原文 `body_fr`、中文译文 `body_cn`、逐句 `lines` 与 **≥5 个**生词标注 `words`。
- 生词的 `word` 使用文中表面形式，`line_seq` 指向对应句子序号，供 i+1 可理解度（coverage）计算与收词链路使用。

## 来源与版权

- 本语料为本项目**原创编写的教学示例**，为法语教学目的自行撰写，未抄袭任何受版权保护的教材原文。
- 文中 CEFR 等级（A1–C2）为**教学标注**，用于分级与 i+1 推荐参考，**非官方定级**。

## 音频

- 本批语料暂未生成音频，`audio_url` 一律为 `null`。
- 前端在 `audio_url` 为空时，使用浏览器 TTS 朗读 `audio_text || body_fr`（`fr-FR`）兜底，不阻塞输入流使用。
