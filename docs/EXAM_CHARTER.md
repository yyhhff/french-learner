## 1. 目标与定位

### 1.1 一句话定位

> 用 2 套原创 B2 风格模拟卷，让用户轻松练熟 DELF B2 / TCF 的题型与答题思路，拿到一份温和的中文练习反馈——**不是真题、不是官方认证、也不预测真实考分**。

### 1.2 定位边界【引用基线 §1】

| 维度 | 本功能**是** | 本功能**不是** |
|------|--------------|----------------|
| 性质 | 原创模拟练习、练题型与思路 | 真题、官方认证、成绩凭证 |
| 成绩 | 练习参考分 + 中文陪练建议 | 真实考分 / 考分预测 |
| 用途 | 内部练习工具、熟悉题型 | 升学/求职/免试资格 |
| 语气 | 温和鼓励、"像婴儿一样自然轻松" | 考试式评判、红叉、排名、达标判定 |

### 1.3 免责声明口径【引用基线 §1，逐字不改】

> **「本卷为原创模拟练习，非 DELF/TCF 官方真题，成绩仅供练习参考」**

- 必须同时出现在 **README** 与 **前端成绩报告结果页**。
- 该否定句是「官方真题」**唯一允许出现**的语境；其余任何用户可见文案禁用（见 §6.3）。

### 1.4 与波一定级 / 既有能力的衔接

```
[波一 定级] 参考等级 ──只读──▶ [波二 考级冲刺] 起点展示 / 建议语境
                                      │
        ┌─────────────────────────────┼──────────────────────┐
        ▼                             ▼                      ▼
  既有 TTS（听力朗读）        既有 ASR（口语转写）    既有 GLM（主观题练习反馈）
        └─────────────────────────────┴──────────────────────┘
                                      │
                    练习记录写入波一既有记录表（允许重复）
```

| 衔接点 | 产品语义 | 责任边界 |
|--------|----------|----------|
| EX-A 起点读取 | 考级冲刺读取波一定级的参考等级，作为"起点展示"与练习建议语境（如"从你现在的参考等级出发"） | **只读**，不改该等级、不做定级；定级归波一 |
| EX-B 零回归 | 不触碰既有 i+1 输入流推荐与既有端点（基线 §8） | 不改推荐算法、不改表结构 |
| EX-C 能力复用 | 听力走既有 TTS、口语走既有 ASR、主观题走既有 GLM（基线 §2） | 零新增依赖 |
| EX-D 数据落库 | 练习记录写入波一既有记录表（基线 §2/§6） | 允许重复交卷、每次写一条（见 AC9） |

## 2. 用户流程

### 2.1 主流程【对齐基线 §7】

| 步骤 | 用户动作 | 系统行为 | 产品要点 |
|------|----------|----------|----------|
| S1 进入 | 点第 4 个 Tab「🏆 考级冲刺」 | 展示选卷页：2 套卷（DELF B2 / TCF B2 风格） | 只展示卷名/类型/简介/题数/满分，**不含题目** |
| S2 选卷 | 选一套卷 | 加载该卷 8 题的公开视图 | 零答案泄露；法语题干、法语听力朗读文本 |
| S3 答题 | 6 道单选 + 1 道写作文本框 + 1 道口语 | 听力/口语题提供 🔊 按钮调既有 TTS 朗读；口语题提供 🎙 按钮走既有 ASR 转写成文本后提交 | 无倒计时、不显示对错、不即时打分 |
| S4 交卷 | 点"交卷看看反馈" | 校验作答后提交 → 判分 → 写记录 → 生成成绩报告 | API 失败给温和重试提示、不清空已答 |
| S5 成绩报告 | 查看报告 | 总分 / 各项得分 / 中文反馈 / 薄弱建议 / 免责声明 / "再做一次" | 温和文案、无红叉、无排名、不写"达标/未达标" |
| S6 再做一次 | 点"再做一次" | 重新选卷或重做同一套 | 允许重复交卷，每次新写一条记录 |

### 2.2 状态与分支

| 场景 | 处理 | 文案口径 |
|------|------|----------|
| 试卷数据缺失 | 选卷页展示空列表、不报错（基线 §6） | "试卷还在准备中，稍后再来看看～" |
| 选了不存在的卷 | 温和提示回到选卷页 | "这套卷子暂时找不到，换一套试试～" |
| 作答不完整 / 非法 | 温和提示补全，不阻断返回修改 | "还有题目没做完哦，再看看～" |
| 主观题评分降级 | 该题明示"暂未评分"，客观题照常出分，报告列未评分题 | "这道题先不打分，多练几次会更顺～" |
| API / 网络失败 | 保留已答，温和重试 | "网络开小差了，再试一次就好～" |
| 重复交卷 | 允许，每次写一条新记录 | "想再练一遍？随时可以～" |

## 3. 题型与分值说明【逐条引用基线 §3 锁定项，不另定】

> 本节题数 / 分布 / 分值 / 等级区间**逐字以 `EXAM_BASELINE.md` v1.0 §3 为准**，PM 不新增、不改写、不另定阈值；仅负责等级区间的**温和中文文案**。物理字段与实现见架构契约。

### 3.1 试卷（2 套原创卷）

| 卷 | 考试类型 | 定位 |
|----|----------|------|
| 第 1 套 | DELF B2 风格 | 原创模拟练习，练题型与思路 |
| 第 2 套 | TCF B2 风格 | 原创模拟练习，练题型与思路 |

### 3.2 题量与题型分布（每套 8 题）

| 题型 | 数量 | 分布 | 分值 |
|------|:---:|------|:---:|
| 客观单选 | 6 | 阅读理解×2 / 词汇语法×2 / 听力理解×1（带朗读文本）/ 观点逻辑×1 | 每题 10 分 |
| 书面表达 | 1 | 中文题目说明 + 字数要求 | 20 分 |
| 口语表达 | 1 | 中文情境说明 + 法语题目（前端朗读） | 20 分 |
| **合计** | **8** | — | **满分 100** |

- 6×10 = 60，+ 20 + 20 = **100 分**（基线 §3 锁定）。
- 题型枚举仅三类：客观单选 / 书面表达 / 口语表达（基线 §3 锁定）。
- 听力题不存音频文件：其法语文本由前端调既有 TTS 朗读（基线 §3）。

### 3.3 等级参考区间【锁定】+ 温和文案

> 区间与标签**逐字沿用基线 §3**，仅作**鼓励性表述、非 CEFR 判定、非达标判定**。PM 补充温和文案，**不得用"达标/未达标"**。

| 分数区间 | 基线标签【锁定】 | 温和中文文案（PM 写） |
|----------|------------------|------------------------|
| ≥ 80 | 很稳 | 这份卷子做得很稳，思路和表达都挺到位，继续保持就好～ |
| 60–79 | 接近目标 | 离目标越来越近啦，把想再练的地方多练几次会更顺～ |
| 40–59 | 继续加油 | 已经摸到题型的感觉了，多练几套会越来越轻松～ |
| < 40 | 多练几次就好 | 刚熟悉题型很正常，多做几套就顺手啦，慢慢来～ |

## 4. 主观题与降级的产品语义【逐条引用基线 §4 锁定项，不另定】

> 本节判分 / 降级规则**逐字以 `EXAM_BASELINE.md` v1.0 §4 为准**；PM 只复述产品语义。GLM 评分提示词 / rubric / 端点字段 / 错误码由架构契约负责，本章程**一律不写**。

### 4.1 判分语义

| 题型 | 判分方式 | 结果性质 |
|------|----------|----------|
| 客观单选 | 服务端按答案下标判分，答对得该题分值、答错 0（基线 §4） | 100% 可自动判定 |
| 书面表达 / 口语表达 | GLM 按 rubric 评分，严格产出结构化结果（得分 + 简体中文反馈），复用既有 GLM 通道（基线 §2/§4） | 属**练习反馈**，不得写成"官方评分" |

### 4.2 降级语义【锁定 · 关键】

触发条件（基线 §4）：无 key / 401 / 超时 / 5xx / 结构化结果解析失败。

| 降级要求 | 产品语义 |
|----------|----------|
| 不打断 | 上述任一情况**绝不向前端抛服务端错误**，客观题照常出分，练习可继续完成 |
| 明示不静默 | 该题标记为"暂未评分"，给出温和文案「这道题先不打分，多练几次会更顺～」（基线 §4 逐字） |
| 报告可见 | 成绩报告**显式**列出未评分题与数量，前端可见「本次有 N 题暂未评分，分数只作参考」（基线 §4 逐字） |
| 不虚低 | 总分**只累加已评分题目**得分，不得把"暂未评分"按 0 分静默计入后给用户一个虚低总分（基线 §4） |

### 4.3 成绩报告产出（产品语义）

| 产出项 | 说明 |
|--------|------|
| 总分 | 已评分题目得分之和（非"满分 100 的绝对占比"），配合未评分说明 |
| 各项得分 | 客观题 / 书面表达 / 口语表达分项呈现；未评分项标注"暂未评分" |
| 中文反馈 | 主观题的简体中文陪练反馈；降级题用温和占位文案 |
| 薄弱建议 | 依据作答给出的温和练习方向，不打红叉 |
| 未评分信息 | 未评分题列表 + 数量，报告与前端均可见 |
| 免责声明 | 基线 §1 原文，结果页可见 |
| 再做一次 | 重做入口，允许重复交卷 |

## 5. 验收标准（AC1–AC12，可度量）

| 编号 | 验收项 | 度量方式 | 通过标准 |
|------|--------|----------|----------|
| AC1 | 试卷规模 | 试卷列表端点返回 | 恰好 2 套（DELF B2 / TCF B2 风格）；各卷类型/标题/简介/题数/满分齐备，且**题数=8、满分=100** |
| AC2 | 每套题结构 | 试卷详情题目统计 | 每套 8 题 = 6 客观单选 + 1 书面表达 + 1 口语表达；客观单选分布为阅读理解×2/词汇语法×2/听力理解×1/观点逻辑×1，且均为四选项 |
| AC3 | 分值一致 | 题目分值核对 | 客观单选每题 10（合计 60）、书面表达 20、口语表达 20，满分 100，与基线 §3 逐项一致 |
| AC4 | 客观题判分正确 | 构造全对/全错/混合答案集自动判分 | 客观题判分 **100% 正确**（答对=10、答错=0）；总分 = 已评分题得分之和 |
| AC5 | 主观题中文反馈 | 正常态提交书面/口语作答 | 书面表达与口语表达均返回**简体中文反馈**（非空、非占位）与 0..该题分值的得分；文案为"练习反馈"，无"官方评分" |
| AC6 | 降级零 500 | 逐一模拟 无key / 401 / 超时 / 5xx / 解析失败 五种路径 | 五种路径**零 500**（基线 §4）；客观题照常出分；该题标记"暂未评分"并给温和文案 |
| AC7 | 未评分题明示 | 降级态成绩报告 + 前端 | 报告显式给出未评分题列表与数量；前端可见「本次有 N 题暂未评分，分数只作参考」；**总分不把未评分题按 0 分静默计入**（对比验证无虚低总分） |
| AC8 | 取卷零答案泄露 | 取卷类 GET 响应字段扫描 | 列表不含任何题目；详情公开视图**零**服务端专用信息（答案下标、中文解析、评分要点、参考范文等，基线 §5）下发，命中=0 |
| AC9 | 重复交卷多写 | 同一卷连续提交两次 | 练习记录表**新增 2 条**考级练习记录，各自可查；无"只写一次"限制（基线 §6） |
| AC10 | 零回归 | 既有端点回归 + 健康检查 | 既有 i+1 输入流推荐与既有端点路径/入参/出参不变；健康检查版本不变；前端既有 3 Tab 与既有函数不破坏（基线 §8） |
| AC11 | 文案禁用词零命中 | 全链路用户可见文案扫描 | 锁定禁用词命中=0（**例外**：免责声明否定句允许"官方真题"）；结果页无"达标/未达标/红叉/排名/倒计时" |
| AC12 | 免责 + 前端闭环 | 端到端走查 | 免责声明基线 §1 原文在**结果页与 README 双可见**；选卷→答题→交卷→报告→再做一次 全链路可走通；听力 🔊 / 口语 🎙 可用；API 失败有温和重试提示 |

**完成判定（DoD）**：AC1–AC12 全部通过；免责声明与禁用词口径经总指挥确认；本章程、`EXAM_BASELINE.md` v1.0、`ARCHITECTURE_EXAM.md` 三者一致；独立 QA 出具验收报告。

### 6.2 推荐 / 禁用说法表

|------|------------|------------|

### 6.3 禁用词精确口径【引用基线 §1】

- 锁定禁用词：`官方认证 / 权威 / 证书 / 保过 / 真题`。
- **唯一例外**：免责声明否定句「本卷为原创模拟练习，非 DELF/TCF 官方真题，成绩仅供练习参考」中的"官方真题"允许出现；除此之外，全链路用户可见文案命中数须为 **0**（AC11）。
- 另禁：`达标 / 未达标`（基线 §3 明确不得用）、红叉、排名、倒计时（基线 §1/§7）。
