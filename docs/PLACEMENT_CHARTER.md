## 1. 目标与定位

### 1.1 一句话定位

> **一组 12 题的轻松法语小自测**，几分钟内给用户一个"参考等级"，让原本写死的 A2 变成贴合本人的起点，从而让 i+1 推荐与后续考级冲刺都对准他真实的水平。

### 1.2 定位边界（重要）

| 维度 | 本功能**是** | 本功能**不是** |
|------|--------------|----------------|
| 性质 | 快速自评、参考等级、内部教学工具 | 官方认证、权威证书、第三方测评 |
| 依据 | 本产品自研题组 + 内部算分规则 | DELF / TCF / CEFR 官方真题或授权题库 |
| 结果用途 | 设定 i+1 推荐起点、给出学习建议 | 升学/求职/免试的资格凭证 |
| 语气 | 温和鼓励、"像婴儿一样轻松" | 考试式评判、打分排名、红叉纠错 |

**明确口径**：定级范围锁定 **A2 / B1 / B2** 三级（与产品现状"写死 A2"和"终点 B2"对齐），不设 A1/C1/C2。结果一律称"**参考等级**"，可随时重测。

### 1.3 用户价值

| 编号 | 用户价值 | 说明 |
|------|----------|------|
| V1 | 起点贴合本人 | 告别"所有人都是 A2"，避免内容过易（无聊）或过难（挫败） |
| V2 | 低门槛、零压力 | 无倒计时、单选、几分钟完成，符合"低情感过滤"理念 |
| V3 | 即时可行动 | 结果页直接给出中文解读 + 学习建议 + 推荐内容预览，看完就能学 |
| V4 | 可见成长 | 后续重测可看到等级变化，形成进步反馈 |

## 2. 用户流程

### 2.1 主流程（Happy Path）

| 步骤 | 用户动作 | 系统行为 | 产品要点 |
|------|----------|----------|----------|
| S1 进入 | 首次使用点"快速测一测"，或个人页点"重新测等级" | 展示引导页：说明"快速自评、约 3 分钟、12 道选择题、随时可重测" | 措辞轻松，禁用"考试/认证" |
| S2 答题 | 逐题作答：法语题干 + 4 选 1 | 记录每题答案；可前后翻页、可改答案 | **无倒计时**、不显示对错、不打分 |
| S3 交卷 | 点"看看我的等级" | 校验是否全部作答；未答题目温和提示，不阻断返回修改 | 未全部作答前不提交、不写回 |
| S4 结果 | 查看结果页 | 展示：参考等级徽章 + 中文解读 + 学习建议 + 推荐内容预览 + "再测一次" | 全程鼓励式，不给红叉/排名 |
| S5 写回 | （S3 提交成功时同步完成） | 服务端判分定级、写回 `users.cefr_level`；后续推荐按新等级 i+1 | 用户无感，结果页即可看到推荐变化 |

### 2.2 状态与分支

| 场景 | 处理 | 文案口径 |
|------|------|----------|
| 中途退出 | 不写回、不判分；重进从头开始（轻量设计，不做断点续答） | "没关系，随时可以重新开始" |
| 未答完就交卷 | 列出未答题号，温和提示；不阻断返回 | "还有 N 题没做哦，要不要再看看？" |
| 提交网络失败 | 保留已答，提示重试；不清空、不写回 | "网络开小差了，再试一次就好" |
| 重复提交 | 产品要求结果可复现（同一答卷多次提交结果一致）；幂等实现交架构师 | 不出现"等级忽高忽低" |
| 重测 | 允许随时重测，新结果覆盖旧值 | "想更新等级？随时可以再测一次" |

## 3. 题目规格

### 3.1 数量与分布

| 项目 | 规格 |
|------|------|
| 总题数 | **12 题**（区间 9–12，取上限以获得更稳定的自评结果） |
| 等级分布 | A2 / B1 / B2 **各 4 题**（区间 3–4，取上限） |
| 题型 | 单项选择，每题 **4 个选项**（1 正确 + 3 干扰） |
| 题干语言 | 法语（`prompt_fr`），必要时附简短法语情境句 |
| 覆盖技能 | 词汇 / 语法 / 理解 三类，每级 3 类各覆盖（4 题中至少含 3 类） |
| 作答形式 | 无倒计时、可返回修改、不即时反馈对错 |

### 3.2 各级题目侧重

| 等级 | 能力定位 | 词汇侧重 | 语法侧重 | 理解侧重 |
|------|----------|----------|----------|----------|
| A2 | 日常简单交流 | 高频生活词、数字/时间/方位 | 现在时、名词性数、基础介词 | 短句/标识/简单指令理解 |
| B1 | 独立表达与旅行场景 | 抽象与情感词、短语动词 | 复合过去时、将来时、条件式 | 短文主旨、日常对话理解 |
| B2 | 较复杂抽象表达 | 论点/连接词、书面语词 | 虚拟式、关系代词、被动态 | 观点态度、段落逻辑理解 |

### 3.3 单题字段清单（产品逻辑视图）

> 物理字段名/类型以架构契约为准；下表为产品必须语义，缺一不可。

| 字段 | 含义 | 取值/约束 | 产品用途 |
|------|------|-----------|----------|
| `id` | 题目唯一标识 | 全局唯一 | 答题定位、答案回传 |
| `level` | 难度等级 | `A2` / `B1` / `B2` | 分组计分 |
| `skill` | 考查技能 | `词汇` / `语法` / `理解` |  Coverage 校验、结果维度解读 |
| `prompt_fr` | 法语题干 | 法语文本，可含情境句 | 用户作答看到的内容 |
| `options` | 选项列表 | 长度固定 4，顺序随题目版本固定 | 用户选择 |
| `correct_index` | 正确选项下标 | 0–3，**仅服务端可见** | 判分；**绝不下发到前端** |
| `explanation_zh` | 中文解析 | 温和鼓励式 | 结果页/回顾页解读 |

### 3.4 题库与版本

| 要求 | 说明 |
|------|------|
| 题组版本 | 每次取卷携带 `version` 标识，答卷回传同一版本以便判分复现 |
| 答案保密 | `GET` 取卷接口**不得**返回 `correct_index` 等正确项信息 |
| 可扩充 | 题库按等级可扩充，取卷时按版本规则各取 4 题（抽样策略交架构师） |

## 4. 算分与定级规则

### 4.1 计分（答对得分、按级别加权）

| 等级 | 单题权重（答对得分） | 题数 | 该组满分 |
|------|:---:|:---:|:---:|
| A2 | 1 | 4 | 4 |
| B1 | 2 | 4 | 8 |
| B2 | 3 | 4 | 12 |
| **合计** | — | **12** | **24** |

- 记各组答对题数为 `c_A2 / c_B1 / c_B2`（各 0–4）。
- 加权总分 `S = c_A2×1 + c_B1×2 + c_B2×3`，取值范围 **0–24**。
- 答错得 0；答对得该题权重分。

### 4.2 定级阈值（清晰、可测试、边界明确）

取**满足的最高等级**；若两级门槛均不满足，则**保底 A2**（与产品下限/现状一致）。

| 判定等级 | 必要条件（须**全部**满足） | 边界含义 |
|----------|---------------------------|----------|
| **B2** | `S ≥ 20` **且** `c_A2 ≥ 3` **且** `c_B1 ≥ 3` **且** `c_B2 ≥ 3` | 总分够高，且三级均无明显漏洞 |
| **B1** | `S ≥ 10` **且** `c_A2 ≥ 3` **且** `c_B1 ≥ 3` | 中级达标，且 A2 基础扎实 |
| **A2** | 其他一切情况（含 `c_A2 < 3`） | 保底，避免给初学者过高起点 |

**分组下限的作用**：防止"只蒙对几道 B2 难题就升级"——判定高级别必须建立在低级题也达标的前提上。

### 4.3 边界测试用例（验收必测）

| 用例 | (c_A2, c_B1, c_B2) | 加权总分 S | 期望等级 | 说明 |
|------|:---:|:---:|:---:|------|
| TC1 全对 | (4,4,4) | 24 | **B2** | 上限边界 |
| TC2 B2 临界达标 | (3,4,3) | 20 | **B2** | B2 阈值下边界（=20） |
| TC3 B2 总分够但 B2 组不足 | (4,4,2) | 18 | **B1** | c_B2=2<3，被分组下限挡住 |
| TC4 B1 临界达标 | (4,3,0) | 10 | **B1** | B1 阈值下边界（=10） |
| TC5 B1 总分不足 | (3,2,0) | 7 | **A2** | S<10 降级 |
| TC6 B2 蒙对但基础差 | (0,0,4) | 12 | **A2** | c_A2=0<3，保底 |
| TC7 全错 | (0,0,0) | 0 | **A2** | 下限边界 |
| TC8 总分高但基础组不足 | (2,4,4) | 22 | **A2** | c_A2=2<3，不满足 B1/B2 的分组下限 → 保底 A2 |

> **TC8 说明**：按 4.2 规则，B1/B2 均要求 `c_A2 ≥ 3`，故 (2,4,4) 虽 S=22 仍判 **A2**。此用例专门验证"分组下限优先于总分"，即**总分再高也不能越过未达标的基础组**。最终以 4.2 规则表为唯一判定依据。

### 4.4 定级结果产出

| 产出项 | 说明 |
|--------|------|
| 参考等级 | `A2` / `B1` / `B2` |
| 加权总分 | `S`（0–24），用于结果页展示与进度感 |
| 维度提示 | 按 `skill` 统计薄弱项（词汇/语法/理解），用于生成建议 |
| 中文解读文案码 | 由等级映射的稳定文案标识（文案内容见第 7 节口径） |

## 5. 两个 API 的产品语义

> 仅描述**产品语义**；请求/响应字段、错误码、鉴权、幂等等物理细节交架构师在架构契约中定义。

### 5.1 `GET /api/assessment/questions` —— 取卷

| 项目 | 产品语义 |
|------|----------|
| 目的 | 给用户发起一次定级提供"一套尚未作答的题目" |
| 返回内容 | 12 道题（三级各 4）、题组 `version`；题目仅含用户可见字段 |
| 关键约束 | **不得下发正确答案/正确下标**；不得下发已标注解析中的答案泄露信息 |
| 状态性 | 产品不要求跨请求保存答题草稿（断点续答不做）；取卷只负责发卷 |
| 幂等性 | 同一 `version` 重复取卷应得到同一组题（保证答卷可判分复现） |
| 失败语义 | 取卷失败时前端给出温和重试提示，不进入答题 |

### 5.2 `POST /api/assessment/submit` —— 交卷判分

| 项目 | 产品语义 |
|------|----------|
| 目的 | 接收用户答卷，完成判分 → 定级 → 写回 → 返回结果 |
| 入参语义 | 携带 `version` + 每题答案（题 id → 选项下标）；必须能对应到取卷时的题组 |
| 服务端动作 | 按第 4 节规则判分定级 → 写回 `users.cefr_level` → 生成结果产出（等级/总分/建议/文案码） |
| 返回内容 | 参考等级 + 中文解读 + 学习建议 + 维度提示 + 推荐预览入口 |
| 关键约束 | 未全部作答时服务端应拒绝判分/写回（交卷完整性由前后端共同保证） |
| 幂等性 | 同一答卷重复提交，结果须一致、等级不抖动（实现交架构师） |
| 失败语义 | 判分/写回失败时**不更新** cefr_level；前端保留答卷并提示重试 |

## 6. 验收标准（可度量的产品验收项）

| 编号 | 验收项 | 度量方式 | 通过标准 |
|------|--------|----------|----------|
| AC1 | 题目数量与分布 | 取卷结果统计 | 单次取卷 12 题，A2/B1/B2 各 4 题，均为 4 选项单选 |
| AC2 | 技能覆盖 | 题目 `skill` 统计 | 每级 4 题覆盖词汇/语法/理解 ≥ 3 类 |
| AC3 | 答案保密 | 取卷响应字段审计 | 响应中**零**正确答案/正确下标泄露 |
| AC4 | 定级正确性 | 第 4.3 节用例集自动执行 | TC1–TC8 期望等级 **100%** 一致 |
| AC5 | 边界完备 | 阈值 ±1 用例 | 20/19、10/9、分组 3/2 等边界分别验证，结果符合规则表 |
| AC6 | 写回生效 | 提交后查 `users.cefr_level` | 提交成功后字段更新为判定等级 |
| AC7 | 推荐联动 | 提交前后调用 `/api/input/recommend` | 新 `target_level` 按新等级 i+1 变化，且无需改推荐算法 |
| AC8 | 未答不写回 | 未答完交卷 | cefr_level 不变，前端提示未答题 |
| AC9 | 幂等一致 | 同一答卷提交两次 | 两次结果等级一致，cefr_level 不被重复异常改写 |
| AC10 | 文案合规 | 全链路文案扫描 | "官方/认证/权威/证书"等禁用词命中数 = 0 |
| AC11 | 低压力体验 | 交互检查 | 无倒计时、无对错即时反馈、可返回改答案 |
| AC12 | 契约一致 | 前后端字段逐项核对 | 与架构契约字段零偏差 |

**完成判定（DoD）**：AC1–AC12 全部通过；定级规则用例集 100% 一致；契约经 PM 与架构师交叉评审通过；文案口径经总指挥确认。

## 7. 风险与文案口径

### 7.1 风险登记（产品侧）

| 编号 | 风险 | 等级 | 影响 | 缓解措施 |
|------|------|:----:|------|----------|
| PR1 | 自评准确性有限（蒙题/状态波动） | 中 | 等级偏离真实水平 | 定位"参考等级"、强调可重测；多级题 + 分组下限抑制偶然升级；结果页给"如果觉得不准，可再测"入口 |
| PR2 | 与官方 CEFR/考级认证被混淆 | 高 | 误导用户、合规/口碑风险 | 禁用"官方认证"等措辞（见 7.2）；全链路统一"快速自评/参考等级"；引导页显著声明非权威测评 |
| PR3 | 写死 A2 改为动态值影响既有推荐体验 | 中 | 老用户推荐内容突变 | 提交成功才写回；结果页展示推荐预览，让用户有预期；保留"重测"自行校准 |
| PR4 | 题库固定、答案被记忆 | 低 | 重测失真 | 题库按级可扩充 + 版本化抽样（策略交架构师）；提醒"真实水平比分数更重要" |
| PR5 | 文案过于考试化，抬高情感过滤 | 中 | 违背"像婴儿一样轻松"理念 | 统一鼓励式文案（见 7.2）；无倒计时/无红叉/无排名；测试将文案口径纳入验收（AC10） |

### 7.2 文案口径（推荐 vs 禁用）

| 场景 | ✅ 推荐说法 | ❌ 禁用说法 |
|------|------------|------------|
| 功能命名 | 快速测一测 / 等级小自测 | CEFR 官方考试 / 权威定级测试 |
| 结果表述 | 你的**参考等级**是 B1 | 你被**认证**为 B1 / 官方认定 B1 |
| 解读语气 | "看起来你已经能轻松应对旅行对话啦" | "你答错了 X 题，能力不足" |
| 不准时 | "觉得不太准？随时可以再测一次" | "测评失败/你测错了" |
| 进度反馈 | "继续保持，离 B2 又近了一步" | "未达标 / 不合格 / 排名靠后" |
| 纠错 | 结果页给温和解析，不打红叉 | 红叉 / 扣分 / 直接语法说教 |

**口径纪律**：所有面向用户的文案（引导页、结果页、错误提示）统一采用上表推荐说法；涉及能力与等级时一律用"参考""大约""看起来"，如实说明这是内部自评而非第三方验证，不夸大。
