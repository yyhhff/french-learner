右栏布局 · 5 版设计方案

约束：右栏固定 280px；「记忆小账本」（紧凑，约 390px 高）与「本场景生词」（长列表）都要首屏可见、互不挤走。

参考来源（GitHub 成熟模式）：GitHub/GitLab 详情页右栏的「紧凑元信息分区」、Tabler / shadcn/ui dashboard 的 KPI 压缩条（数字+小标签一行排开）、侧栏 Tab 复用空间模式（angular-ui-skills / absolute-ui 的 dashboard patterns 参考）。以下 mockup 全部使用应用现有设计变量，所见即所得。

方案对比矩阵

评分口径：首屏双目标（账本可见 + 生词可见）、感知度、实现风险、小屏兼容。

方案账本首屏可见生词首屏可见感知度实现量主要风险
A 现状（账本在上）✓✗ 生词被挤走高但失衡—已确认不满足
B Tab 切换△ 要点一下✓中小账本感知度下降
C KPI 压缩条✓ 一行三数✓ 满高高（核心数常驻）小（改一处面板 HTML+CSS）次级指标移位到成长页
D 融入顶栏✓ 全局✓高但拥挤中（动顶栏）顶栏折行、小屏挤
E C+吸顶✓ 滚动也常驻✓最高中（+sticky 容器）sticky 在部分面板布局需细调
推荐：方案 E（方案 C 基础 + 吸顶）——账本压成一行「待复习 46 · 本周 +46 · 📝 复习」吸顶条常驻生词卡顶部， 生词列表拿到全部高度且内部滚动时账本条不动；完整账本（已掌握/正确率/连续/累计对话）职责归「🌱 我的成长」页。 若想最稳，退一档选纯方案 C（同布局、不吸顶）。
